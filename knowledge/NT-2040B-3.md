# NextLED Professional 3 Temperature Color Matching Light (NT-2040B-3)

## What it is
The NextLED NT-2040B-3 is a handheld color matching light with three color temperatures, rated CRI 96 plus so colors read true for paint work. It has a focus lens, a rotating base with a magnet, and a hidden hook and magnet at the back for hands free use. It charges on a base that can be wall mounted. It is a color matching tool, not a general area work light. Some listings show the number as NT-20408-3, which is the same light.

## Key features
- 3 color temperatures for critical color matching and finding imperfections
- CRI 96 plus rated for color accuracy
- Strong ABS housing with a focus lens
- Rotating base with a magnet that also adjusts the lighting angle
- Hidden hook and magnet at the back for hands free working
- Mountable charging base for a wall mounted charging station
